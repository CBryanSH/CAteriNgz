# CAteriNgz

Semester 2 Project
CAteriNgz is a catering website for a variety of food types that's made using html, css, and JavaScript for the database and logic.

Navigation Bar
In the navigation bar, the CAteriNgz logo can be clicked to always return to the homepage, and the text for the other pages can also be clicked to go to each respective page.

HomePage
The homepage has a main rotating image and several buttons. The first is the button below the text above, which leads to the Our Products page. After that, there is also a button leading to the About Us page, located below the short description.

Our Products
This page shows all the options provided by the business. There are four buttons below the About Us text that can be clicked to filter the types of menus offered.

About Us
This page provides a clearer explanation of the catering business. The social media icons can be hovered over to enlarge them, and there is also a button that changes color when hovered over.

Testimony
This page contains the given testimonials. All images can be hovered over to create a more interactive feel.

Register
This page displays several fields that users must fill out. If left empty when submitted, an alert will appear to prompt users to fill in the missing information.

Footer
In the footer, there are 3 words that change color when hovered over. There are also social media icons that enlarge when hovered over.

Responsiveness
All pages except the Homepage and Register are responsive, meaning they will display properly on screens of any resolution.
